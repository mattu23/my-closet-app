# 学習メモ管理ガイド

## 概要
このディレクトリは、プロジェクト開発に関連する学習メモを管理するための場所です。

## 使用方法

### 1. 新しい学習メモの作成
1. `template.md`をコピーして新しいファイルを作成
2. ファイル名は `YYYY-MM-DD-タイトル.md` の形式で作成
3. テンプレートに従って内容を記入

### 2. メモの構成
- 概要: 学習内容の簡単な要約
- 詳細メモ: 具体的な学習内容
- コード例: 関連するコードスニペット
- 参考リンク: 参考にしたリソース
- 疑問点・課題: 残っている疑問や課題
- 次回の学習計画: 今後の学習予定
- メタデータ: タグや重要度などの管理情報

### 3. ベストプラクティス
- 定期的にメモを更新する
- タグを適切に使用して検索性を高める
- コード例は必要に応じて簡潔に記載
- 疑問点は具体的に記載し、解決したら更新する

### 4. ファイル命名規則
- 日付-タイトル.md の形式
- 例: `2024-03-20-react-hooks-basics.md`

## ディレクトリ構造
```
learning-notes/
├── README.md
├── template.md
└── YYYY-MM-DD-タイトル.md
```
